## 继承的产品要求

用户与 ZuTrade 团队替工厂销售；第一批使用者为 owner 加 1—4 名销售成员。优先自找买家，也保留工厂带来的询盘。工作台首先处理海外买家消息。owner 审核关键报价、折扣和交期；首触达按具体名单和内容批次审核。电脑为主，手机处理紧急消息。

首版验证案例使用 CT-01 棉布袋，虚构工厂和买家均明确标注。产品 12oz、35×40cm、本色、单色单面 logo；500—999 件的模拟价阶 USD 2.40/件，设置费 USD 30。500 件总额 1,230；800 件总额 1,950。价阶外数量待工厂确认，不外推。

生产时间 20 个工作日，以图稿/样品确认与订金确认等约定条件为起点；不等于六周内到达。产品价不含运费、税费和另行报价的样品。货币、有效期、卖方、排除项和起算条件必须进入报价快照。

采用工厂签约、收款和履约的轻资产方式；ZuTrade 管理代理销售过程。费率、佣金结算、订单、资金、物流、ERP 和工厂登录均不在本轮。

## 本地实现补充决定

- pnpm monorepo，Mac 原生运行 web/API/worker，Docker 运行 PostgreSQL；不强制用仿真 x86 镜像。Codex 检查实际 arm64/x64 后选兼容依赖。
- 用私有磁盘存储适配器支撑本地附件/PDF，接口与不可变对象概念保留，未来可换 S3。文件不放 web public 目录，下载经过服务端权限检查。
- Better Auth 采用本地账号密码的基础登录。成员由 owner 建立或通过受控本地初始化，不依赖外发邀请邮件，不开放公众注册。
- 真实获客采用公开目录发现与可选搜索 API 接口，不依赖真实大模型。规则匹配有证据、有版本、可人工修正。
- 搜索 API 默认实现 Brave Search 适配边界；实际启用依赖账号、凭据和允许保存所需结果的条款。公开目录模式提供不需要搜索 API 密钥的真实发现路径。具体来源必须实际可读，不能假定任意目录都可抓取。
- 自由文本无法通过受控事实模板证明为常规答复时，提交 owner 审核；本轮不虚构通用语义分类能力。
- 模拟时钟仅用于可控业务场景，真实抓取时间始终使用实际时钟并记录 UTC。
